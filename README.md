# Проект "Другая опера"

## Описание
* Музыкальный облачный сервис. Для тех, чьи любимые альбомы почему-то исчезают с Яндекс-Музыки. Загружайте его сюда и слушайте. В любое время. С любого устройства. Сколько угодно


## API
* Адрес сервера: `config.API_ROOT`
* Получение всех строк таблицы: GET `API_ROOT/<название таблицы>`
* Получение конкретного элемента: GET `API_ROOT/<название таблицы>/one?<параметры url>`
* Создание элемента: POST `API_ROOT/<название таблицы>/one`, JSON с объектом в поле data
* Удаление элемента: DELETE `API_ROOT/<название таблицы>/one`
